# PPTBridge SK Show Checklist

Use this short checklist with the exact deck, OBS scene collection, and control surface that will be used on the event.

## Before the Event

- [ ] Install the correct PPTBridge build for the production computer.
- [ ] Open OBS in normal mode and confirm both PPTBridge source types are available.
- [ ] Put `PPTBridge SK Slide` in the audience Program scene.
- [ ] Put `PPTBridge SK Presenter` in the speaker/confidence scene.
- [ ] Select the same final deck file in both sources.
- [ ] Keep the deck in a permanent show folder; do not run it from Downloads or removable media.
- [ ] Save the OBS scene collection after sources load.

## Deck Rehearsal

- [ ] Check the first slide, every media/animation cue, and the last slide.
- [ ] Press Next once more on the final slide and confirm the slideshow remains visible.
- [ ] Confirm the current slide, next slide, notes, timer, and cue list in Presenter.
- [ ] Confirm embedded audio reaches the intended OBS source/mixer channel.
- [ ] Resize the PowerPoint desktop window and confirm the OBS Slide output stays stable.
- [ ] Close and restart live mode once to verify recovery before show day.

## Control

- [ ] Confirm default OBS hotkeys (`2` next, `1` previous) while OBS is focused.
- [ ] If using a stage clicker, enable Spotlight/Clicker Capture and test PageDown/PageUp while another app is focused.
- [ ] If using Companion, enable local OSC and test Previous, Next, First, Last, Black, and Reload.
- [ ] Confirm controls follow the deck in the current Program scene when multiple decks are open.
- [ ] Confirm loading, live, current/total slide, and error status are visible on the operator control page.

## Five Minutes Before Show

- [ ] Disable sleep, screen savers, notifications, and automatic updates.
- [ ] Connect power and the final displays before opening OBS and PowerPoint.
- [ ] Open the intended OBS scene collection and put the correct scene in Program.
- [ ] Start PowerPoint Live Mode if the deck uses animations or media.
- [ ] Return to slide one and clear Black Screen.
- [ ] Do one final Next/Previous test from the real clicker or Companion panel.

## Recovery Notes

- If PowerPoint closed its slideshow, use `Start / Restart PowerPoint Live Mode`.
- If the live image stopped updating, use `Reattach Live PowerPoint Window`.
- If a deck does not respond, verify its scene is in Program before using global controls.
- Keep the static preview available while live mode is starting or recovering.
