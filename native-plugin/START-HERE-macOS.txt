PPTBridge SK for OBS - macOS
Created by Srdjan Kotarlic

FAST INSTALL

1. Make sure you downloaded the right ZIP:

   Apple Silicon Macs:
   pptbridge-obs-macos-apple-silicon.zip
   Use this for M1, M2, M3, and M4 Macs.

   Intel Macs:
   pptbridge-obs-macos-intel.zip
   Use this for older Macs where About This Mac says Processor: Intel.

2. Double-click:

   1-Install-PPTBridge-SK.command

3. If OBS is open, quit OBS manually and run this installer again.
4. If macOS blocks it, right-click the file and choose Open.
5. The installer will copy the plugin and open OBS.
6. If OBS asks about Safe Mode, choose normal launch.
7. In OBS, add a new source:

   PPTBridge SK Slide

   or

   PPTBridge SK Presenter

WHAT THE TWO SOURCES DO

PPTBridge SK Slide:
- clean slide output for the audience, projector, stream, or recording
- this is the source that should usually run PowerPoint live mode

PPTBridge SK Presenter:
- presenter confidence view with current slide, next slide, timer, and notes
- use this on a stage monitor, presenter scene, or operator preview

BASIC OBS SETUP

1. Add PPTBridge SK Slide to the program/audience scene.
2. Add PPTBridge SK Presenter to the speaker/confidence scene.
3. Select the same .pptx or .pdf file in both sources.
4. For .pptx live mode, open PPTBridge SK Slide properties and click:

   START / RESTART - Open PowerPoint Live Mode

5. For PDF decks, PowerPoint is not needed.
6. PPTBridge SK Presenter stays lightweight and static for notes, next slide,
   timer, and confidence-monitor layouts. Live animations and video are shown
   through PPTBridge SK Slide.

HOTKEYS

Open OBS Settings > Hotkeys and search for PPTBridge SK.

Defaults:

- Next Slide: 2 or Right Arrow
- Previous Slide: 1 or Left Arrow

PPTBridge only moves slides from hotkeys while OBS is the active app.
You can bind different keys in OBS Settings > Hotkeys if needed.

SPOTLIGHT / CLICKER CAPTURE

If a presenter on stage uses a Logitech Spotlight or similar clicker while the
operator uses Chrome, OBS, or another app:

1. In OBS, open Tools > PPTBridge SK: Toggle Spotlight/Clicker Capture.
2. Use the clicker's normal next/previous buttons. PPTBridge captures
   PageDown or Right for next and PageUp or Left for previous
   by default.
3. If macOS asks, allow OBS in System Settings > Privacy & Security >
   Accessibility and Input Monitoring.
4. Restart OBS or toggle the feature again after granting permission.

This makes the clicker drive the PPTBridge deck in the current OBS Program scene
and stops those captured key presses from affecting the focused app. It works for
PPTX live mode and PDF/cached decks. You can still bind custom keys in OBS
Settings > Hotkeys if your clicker sends unusual keys. Normal typing keys such
as 1 and 2 are swallowed while this feature is enabled if you bind them as
custom clicker keys.

POWERPOINT STARTUP

In the PPTBridge SK Slide source properties:

- Leave Auto Start PowerPoint When OBS Opens off if OBS should open quietly.
- Click START / RESTART - Open PowerPoint Live Mode in the highlighted
  PowerPoint Live Start / Stop group when you are ready to launch the slideshow.
  If PowerPoint is not open yet, PPTBridge opens it for you.
- If the slideshow window was closed but PowerPoint is still open, click
  START / RESTART - Open PowerPoint Live Mode again to recover the live session.
- Turn Auto Start PowerPoint When OBS Opens on if you want the slideshow to launch with OBS.
- Leave Close PowerPoint Slideshow When OBS Closes on if OBS should clean up the slideshow on quit.
- Use STOP - Stop PowerPoint Live Mode in the same highlighted group if you want
  to stop the slideshow without quitting OBS.
- Leave PowerPoint Resize Behavior on Lock OBS Output Size if you want to shrink
  the PowerPoint window on your desktop without changing the OBS program output.
- Use Follow Current PPT Window Size only when you intentionally want the resized
  PowerPoint window to affect OBS.

MULTIPLE PPTX DECKS

- Create one OBS scene per deck.
- Add PPTBridge SK Slide and PPTBridge SK Presenter to each scene.
- Select that scene's .pptx in both sources.
- Click START / RESTART - Open PowerPoint Live Mode once for each deck you want ready.
- PPTBridge locks each PowerPoint live session to its exact staged deck file, so
  several slideshow windows can stay open and scene changes control the right deck.

COMPANION / OSC

For Stream Deck or Bitfocus Companion control without keyboard focus:

1. In OBS, open Tools > PPTBridge SK: Toggle Local OSC Control.
2. In Companion, add a Generic OSC connection:
   Host: 127.0.0.1
   Port: 57130
   Protocol: UDP
3. Send OSC paths such as:
   /pptbridge/next
   /pptbridge/previous
   /pptbridge/black

REQUIREMENTS

- macOS 12 or newer
- OBS Studio 30 or newer
- Microsoft PowerPoint for PPTX live mode

PDF decks can be used without PowerPoint.

IF IT DOES NOT SHOW UP

1. Make sure OBS is not in Safe Mode.
2. Restart OBS again.
3. In OBS, open Help > Log Files > View Current Log.
4. Search for:

   PPTBridge SK

If the log does not say "Native plugin loaded", send the OBS log with a bug report:

https://github.com/srdjankotarlic/pptbridge-sk-obs/issues
