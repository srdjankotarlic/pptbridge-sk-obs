PPTBridge SK for OBS - macOS
Created by Srdjan Kotarlic

FAST INSTALL

1. Make sure you downloaded the right ZIP:

   Apple Silicon Macs:
   pptbridge-obs-macos-apple-silicon.zip

   Intel Macs:
   pptbridge-obs-macos-intel.zip

2. Double-click:

   1-Install-PPTBridge-SK.command

3. If OBS is open, let the installer quit it and continue.
4. If macOS blocks it, right-click the file and choose Open.
5. The installer will copy the plugin and open OBS.
6. If OBS asks about Safe Mode, choose normal launch.
7. In OBS, add a new source:

   PPTBridge SK Slide

   or

   PPTBridge SK Presenter

HOTKEYS

Open OBS Settings > Hotkeys and search for PPTBridge SK.

Defaults:

- Next Slide: 2
- Previous Slide: 1

PPTBridge only moves slides from hotkeys while OBS is the active app.
You can bind different keys in OBS Settings > Hotkeys if needed.

POWERPOINT STARTUP

In the PPTBridge SK Slide source properties:

- Leave Auto Start PowerPoint When OBS Opens off if OBS should open quietly.
- Click Start PowerPoint Live Mode when you are ready to launch the slideshow.
- Turn Auto Start PowerPoint When OBS Opens on if you want the slideshow to launch with OBS.
- Leave Close PowerPoint Slideshow When OBS Closes on if OBS should clean up the slideshow on quit.

COMPANION / OSC

For Stream Deck or Bitfocus Companion control without keyboard focus:

1. In OBS, open Tools > PPTBridge SK: Toggle Local OSC Control.
2. In Companion, add a Generic OSC connection:
   Host: 127.0.0.1
   Port: 57130
   Protocol: UDP
3. Send OSC paths such as:
   /pptbridge/next
   /pptbridge/previous
   /pptbridge/black

REQUIREMENTS

- macOS 12 or newer
- OBS Studio 30 or newer
- Microsoft PowerPoint for PPTX live mode

PDF decks can be used without PowerPoint.

IF IT DOES NOT SHOW UP

1. Make sure OBS is not in Safe Mode.
2. Restart OBS again.
3. In OBS, open Help > Log Files > View Current Log.
4. Search for:

   PPTBridge SK

If the log does not say "Native plugin loaded", send the OBS log with a bug report:

https://github.com/srdjankotarlic/pptbridge-sk-obs/issues
