# Present PDF slides directly in OBS — no PowerPoint needed

PPTBridge SK is also a **PDF presentation plugin for OBS on Windows and macOS**. Direct PDF support is already available in the current releases; this guide makes the workflow easier to find and use.

Select a `.pdf` in **PPTBridge SK Slide** and the plugin renders its pages directly. You do not need PowerPoint, a separate PDF reader, display capture, or a folder of manually exported page images.

## What you can do

- Show clean PDF pages to your audience, stream, recording, or OBS projector.
- Add an optional **PPTBridge SK Presenter** source with current/next page preview, timer, and cue list.
- Turn pages or use black screen with source controls, OBS hotkeys, supported clicker keys, or Companion/local OSC.
- Keep one Program scene per PDF when working with several decks.

This is useful for conference slides, training material, agendas, diagrams, and static PDF backups of presentations.

## Get started

1. [Download PPTBridge SK for Windows or Mac](https://srdjankotarlic.github.io/pptbridge-sk-obs/#install), install it, and restart OBS.
2. Add **Sources + → PPTBridge SK Slide**, then select your PDF.
3. Fit the page to the canvas and check Next / Previous and black screen.
4. If you need a speaker display, add **PPTBridge SK Presenter** in a separate scene and select the same PDF.

PDFs render directly, so you do not need to start PowerPoint Live Mode. The macOS Stage Manager workaround for live PowerPoint capture does not apply to PDFs.

PDF pages are static: they do not carry PowerPoint animations, click builds, or embedded audio/video playback. Ordinary PDFs also do not carry PowerPoint speaker notes in a standard form. Use the original PowerPoint file for those features, and rehearse your own files before the event.
