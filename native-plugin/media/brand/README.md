# PPTBridge SK Brand Assets

This folder contains the icon source component and export helper used to generate the GitHub and forum brand assets.

The icon PNG files in `../github/` were exported from the PowerPoint brand deck, because the deck already contains clean, pre-rendered image assets. The social preview is generated from `icons.jsx` so the release text can stay aligned with the public repo status.

Current primary mark: dark graphite app-icon tile with a presenter pane bridged to a cyan broadcast output pane.

Recommended public assets:

- `../github/pptbridge-sk-social-preview.png` - GitHub social preview and release header
- `../github/pptbridge-sk-icon-512.png` - plugin icon preview
- `../github/pptbridge-sk-icon-256.png` - OBS Forum/resource thumbnail
