PPTBridge SK for OBS - Windows Beta
===================================

Use this file only if you are looking at the source tree.
Normal Windows users should download:

  pptbridge-obs-windows-x64-v0.5.0-beta.1.zip

Then:

  1. Extract the ZIP.
  2. Double-click INSTALL.cmd.
  3. Open OBS.
  4. Add PPTBridge SK Slide or PPTBridge SK Presenter from Sources.

What the installer copies:

  obs-plugins\64bit\pptbridge-obs.dll
  data\obs-plugins\pptbridge-obs\locale\en-US.ini
  data\obs-plugins\pptbridge-obs\locale\en-GB.ini

Windows beta scope:

- PowerPoint decks are supported for live-mode testing.
- .pptx is the best-tested format.
- Legacy .ppt decks can be selected and opened through Microsoft PowerPoint.
- PDF input is not enabled on Windows yet.

Production check before a show:

- Confirm both OBS sources appear.
- Load the deck in PPTBridge SK Slide.
- Click START - Open PowerPoint / Start Live Mode.
- Confirm OBS attaches to the live PowerPoint slideshow.
- Test next/previous from OBS and from the presenter clicker.
- Test audio if the deck contains embedded media.
- Confirm Lock OBS Output Size ignores PowerPoint window resizing.
- Confirm hotkeys, OSC, and clicker capture target the current OBS Program scene.
- Confirm multiple OBS scenes can control different PowerPoint decks.
- Keep a normal PowerPoint backup ready until this beta has passed your own venue test.

Known limits:

- PDF input is not enabled in this Windows beta.
- This is a beta; test it on the target OBS/PowerPoint computer before a live show.
- The stable public release is the macOS Apple Silicon v0.4.7 release.
