Present PDFs in OBS without PowerPoint

Already have the slides as a PDF? Open the file directly in PPTBridge SK. Its native PDF renderer puts clean pages into OBS without PowerPoint, a separate PDF reader, or display capture. Add an optional presenter view to see the current page, next page, timer, and cue list while your audience sees only the presentation.

Why use PPTBridge for PDFs?

  • Use the file you already have. Present conference slides, training pages, agendas, or diagrams without converting every page to an image.
  • Keep the audience output clean. The Slide source shows the PDF page without a reader toolbar or desktop around it.
  • See what comes next. The separate Presenter source gives the operator or speaker a current/next preview, timer, and cue list.
  • Build the show in OBS. Combine the page with cameras and graphics, then stream, record, or send the scene to an OBS projector.
  • Control pages from your setup. Use source buttons, OBS hotkeys, supported clicker keys, or Companion/local OSC.

1. Add the clean PDF output

  1. Install PPTBridge SK for your platform and restart OBS.
  2. In the scene intended for the audience, choose Sources + → PPTBridge SK Slide.
  3. Select your .pdf file in the source properties and let it load.
  4. Fit the source to the canvas and use Next / Previous to check page order and readability.
  5. Send the scene to Program when you are ready to show it.
PDFs do not need PowerPoint Live Start. They render directly in the plugin. The macOS Stage Manager workaround for live PowerPoint window capture does not apply to this PDF workflow.

2. Add an optional presenter view

  1. Create a separate scene for the operator or speaker display.
  2. Add PPTBridge SK Presenter and select the same PDF file.
  3. Choose a layout for the current page, next page, timer, and cue list. Adjust preview fit, fill, or crop as needed.
  4. Project this separate scene to the speaker display from OBS, while keeping the clean Slide scene on Program.

The Presenter source is optional. One Slide source is enough if you only need to put PDF pages on the stream or recording.

3. Choose how to turn pages

  • Source controls: next, previous, first, last, and black screen.
  • OBS hotkeys: the default bindings are 2 for next and 1 for previous while OBS is focused. Change them in Settings > Hotkeys.
  • Optional clicker capture: enable Tools > PPTBridge SK: Spotlight/Clicker Capture On/Off for supported presenter keys such as Page Down / Page Up. macOS may ask for the required input permissions.
  • Companion or Stream Deck: follow the Companion, OBS WebSocket, and local OSC guide for control without relying on keyboard focus.

When you have several PDFs, use one audience scene per deck. Shared controls target the PPTBridge deck in the current OBS Program scene.

PDF pages and PowerPoint features

PDF is useful for static slides and as an exported backup of a presentation. It does not preserve PowerPoint animations, click-by-click builds, or embedded audio/video playback. Use the original PowerPoint file and live mode when the presentation depends on those features.

About speaker notes: ordinary PDFs do not carry PowerPoint speaker notes in a standard form. You still get current/next preview, timer, and cue-list guidance. Use the original PowerPoint file when embedded speaker notes are essential.

Check the file before the event

  • Use an unprotected PDF; the Windows renderer does not open password-protected files.
  • Check every page, especially small text, diagrams, and unusual page sizes.
  • Rehearse page controls, black screen, and the separate presenter display.
  • Keep the PDF in a permanent show folder so OBS can find it after a restart.

The published September 7 macOS regression report records checks across five PDFs, including page navigation and blackout/restore. The Windows test guide describes native PDF checks. Rehearse your own files and production setup too.
