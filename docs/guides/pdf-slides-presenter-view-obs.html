Show PDF slides with a separate presenter view in OBS

PPTBridge opens PDF decks directly as native OBS sources on Windows and macOS. The audience gets clean pages while the presenter view shows current and next page, timer, and cue guidance, with no separate PDF window or PowerPoint application.

Direct PDF renderingCurrent + next slideConfidence monitor

Add the audience source

  1. Choose Sources + → PPTBridge SK Slide.
  2. Select the PDF.
  3. Put this source in the Program scene and fit it to the canvas.
  4. Use Next/Previous controls to confirm page order.

Add the presenter source

  1. Create a separate confidence-monitor scene.
  2. Add PPTBridge SK Presenter and select the same PDF.
  3. Choose the layout that best balances current slide, next slide, timer, and cue list.
  4. Project this scene to the speaker display from OBS.
About speaker notes: ordinary PDF files do not carry PowerPoint speaker notes in a standard form. PPTBridge can still provide current/next preview, timer, and cue-list guidance; use the original PowerPoint file when embedded speaker notes are essential.

When PDF is the better choice

  • The deck has no builds, animations, or embedded media.
  • You want the same rendered pages on every production machine.
  • PowerPoint is not installed on the OBS computer.
  • You need quick, direct loading with fewer moving parts.

Operator tips

  • Export the PDF at presentation quality and inspect small text before the show.
  • Check unusual page sizes; the source stays on a stable OBS canvas but may need fit/crop choices.
  • Use one Program scene per deck when several PDFs are open.
  • Keep the source file in a permanent show folder so OBS can find it after restart.
