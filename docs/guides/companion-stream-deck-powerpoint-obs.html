Control PowerPoint in OBS with Companion and Stream Deck

PPTBridge includes local OSC control so slide commands do not depend on keyboard focus and the operator can see useful deck status.

Bitfocus CompanionGeneric OSCLocal machine

1. Enable PPTBridge OSC

  1. Start OBS and load the scene containing your PPTBridge source.
  2. Open Tools -> PPTBridge SK: Local OSC Control On/Off.
  3. Keep Companion on the same computer as OBS. PPTBridge intentionally listens on 127.0.0.1, so slide control is not exposed across the production network.

2. Add a Generic OSC connection

In Companion, add Generic OSC and use:

  • Target host: 127.0.0.1
  • Target port: 57130
  • Protocol: UDP

Create buttons that send messages without arguments:

/pptbridge/previous
/pptbridge/next
/pptbridge/first
/pptbridge/last
/pptbridge/black
/pptbridge/reload

3. Add status feedback

PPTBridge sends status on UDP port 57131. Available values include current and total slide, current/next title, timer, deck and source names, loading/error state, live status, black screen, and cue-list checked state.

Starter layout: open the Companion OSC template. It documents the connection, six core buttons, and every current status path.

Recommended first page

  • PREV and NEXT as the largest buttons.
  • FIRST, LAST, BLACK, and RELOAD as guarded secondary actions.
  • Current slide and total slides on the button text.
  • Live/loading/error indicators where the operator can see them without opening OBS properties.

Test before show day

  1. Put the intended scene in OBS Program.
  2. Press Next from Companion and verify only that deck moves.
  3. Switch to a second Program scene and repeat.
  4. Stop live mode or temporarily select a bad path and confirm your status page makes the state obvious.
