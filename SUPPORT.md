# Support

Use GitHub Issues for support and feedback.

- Bugs: open a [bug report](https://github.com/srdjankotarlic/pptbridge-sk-obs/issues/new?template=bug_report.md)
- Feature ideas: open a [feature request](https://github.com/srdjankotarlic/pptbridge-sk-obs/issues/new?template=feature_request.md)
- v1.0 progress: follow [Issue #1](https://github.com/srdjankotarlic/pptbridge-sk-obs/issues/1)

For bug reports, include:

- OS version
- OBS Studio version
- PPTBridge SK release
- PowerPoint version, if using `.pptx`
- whether the deck is `.pptx` or `.pdf`
- the current OBS log

In OBS, open `Help > Log Files > View Current Log`.
